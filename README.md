# Alchemist — releases

Notarized builds of Alchemist for macOS 26 and the Sparkle update feed (`appcast.xml`) the app
reads. Published from the developer's Mac with `make release`.

Install: open the DMG and drag Alchemist to Applications. Conversions of video, audio, WebP and
office documents need, from Homebrew: `brew install ffmpeg webp` and
`brew install --cask libreoffice`.
